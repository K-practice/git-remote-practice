# Git Remote Practice

## 概要

GitとGitHubの基本操作を練習するためのリポジトリです。

## 使用技術

- Git
- GitHub
- Python

## 主な学習内容

- Gitによるバージョン管理
- リモートリポジトリへのpush
- cloneとpull
- branchを使った開発
- mergeとコンフリクト解決
- GitHub Issue
- Pull Request
- GitHub Flow

## 環境構築

リポジトリをcloneします。

```bash
git clone https://github.com/K-practice/git-remote-practice.git
```

プロジェクトフォルダに移動します。

```bash
cd git-remote-practice
```

## 使用方法

Git/GitHubの各操作を実際に試しながら、
変更履歴やブランチの動きを確認するために使用します。
